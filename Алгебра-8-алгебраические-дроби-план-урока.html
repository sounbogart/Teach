Повторение

Учитель

Задаёт три вопроса, ответы устно и коротко записывает на доске:

  • При каких значениях x имеет смысл дробь 5x² − 9?
  • Сократите дробь a² − 4aa² − 16.
  • Приведите дроби 1x и 1x + 1 к общему знаменателю.
Ученики

Отвечают с места, при необходимости раскладывают на множители.

Показать ответыСкрыть ответы
  1. Знаменатель не должен быть равен нулю: x² − 9 = (x − 3)(x + 3) ≠ 0, значит, x ≠ 3 и x ≠ −3.
  2. Числитель: a² − 4a = a(a − 4). Знаменатель: a² − 16 = (a − 4)(a + 4). После сокращения на a − 4 получаем aa + 4 при a ≠ 4 и a ≠ −4.
  3. Общий знаменатель x(x + 1): 1x = x + 1x(x + 1) и 1x + 1 = xx(x + 1).
4–9 мин

Алгоритм преобразования

Учитель объясняет идею из учебника: преобразование любого рационального выражения сводится к сложению, вычитанию, умножению и делению дробей, а результат всегда можно записать в виде одной рациональной дроби. Дальше вместе записывают алгоритм.

Запись в тетрадь: алгоритм
  1. Записать допустимые значения: все знаменатели не равны нулю (и делитель не равен нулю).
  2. Выполнить действия в скобках, приводя дроби к общему знаменателю.
  3. Выполнить умножение и деление. Деление заменить умножением на обратную дробь.
  4. Выполнить сложение и вычитание.
  5. Разложить на множители и сократить. Проверить ответ числом.
Как делить на многочленСкрыть

Многочлен можно записать как дробь со знаменателем 1. Поэтому деление на многочлен P заменяют умножением на дробь 1P. Например, деление на x² − 3y² равносильно умножению на 1x² − 3y².

Второй образец: вычесть дробь из многочленаСкрыть образец

Преобразуем выражение x + 1 − x² + 3xx² − 9.

  1. Допустимые значения: x² − 9 ≠ 0, то есть x ≠ 3 и x ≠ −3.
  2. Сократим дробь: x² + 3xx² − 9 = x(x + 3)(x − 3)(x + 3) = xx − 3.
  3. Вычитаем из многочлена: x + 1 − xx − 3 = (x + 1)(x − 3) − xx − 3 = x² − 2x − 3 − xx − 3 = x² − 3x − 3x − 3.
  4. Проверка при x = 4: 5 − 287 = 5 − 4 = 1, а 16 − 12 − 34 − 3 = 1.

Ответ: x² − 3x − 3x − 3 при x ≠ 3, x ≠ −3.

9–14 мин

Образец у доски: «многоэтажная» дробь

Учитель

Пишет выражение и показывает два способа. Ученики выбирают, какой удобнее.

xy − yxxy + yx − 2
Ученики

Записывают допустимые значения, затем повторяют оба способа у себя в тетради.

Показать решение двумя способамиСкрыть решение
  1. Допустимые значения: x ≠ 0, y ≠ 0, а также знаменатель большой дроби не равен нулю. Он равен (x − y)²xy, значит, x ≠ y.
  2. Способ 1. Отдельно числитель: xy − yx = x² − y²xy. Отдельно знаменатель: xy + yx − 2 = x² + y² − 2xyxy = (x − y)²xy. Делим: x² − y²xy · xy(x − y)² = (x − y)(x + y)(x − y)² = x + yx − y.
  3. Способ 2. Умножим числитель и знаменатель большой дроби на xy. Числитель: (xy − yx) · xy = x² − y². Знаменатель: (xy + yx − 2) · xy = x² + y² − 2xy = (x − y)². Получаем x² − y²(x − y)² = x + yx − y.
  4. Проверка при x = 3, y = 1: (3 − 13) : (3 + 13 − 2) = 83 : 43 = 2, а 3 + 13 − 1 = 2.

Ответ: x + yx − y при x ≠ 0, y ≠ 0, x ≠ y.

Запись в тетрадь

Чтобы упростить «многоэтажную» дробь, можно упростить числитель и знаменатель отдельно и разделить, а можно умножить числитель и знаменатель на общий знаменатель всех маленьких дробей (основное свойство дроби).

Итог и вопрос на выходе

Вопросы классу
  • В каком порядке выполняют действия в выражении с дробями?
  • Как поделить на многочлен?
  • Зачем записывать допустимые значения, если в ответе получилась простая дробь?
Показать ответыСкрыть ответы
  1. Сначала скобки, потом умножение и деление, потом сложение и вычитание.
  2. Заменить делением на многочлен P умножение на дробь 1P.
  3. Исходное выражение имеет смысл не при всех значениях. Ответ должен быть верен только для допустимых значений, и запись их показывает, где выражение определено.
Вопрос на выходе (в тетрадь, без обсуждения)

Упростите (1a − 1b) : b − aab и запишите допустимые значения.

Показать ответСкрыть ответ
  1. Допустимые значения: a ≠ 0, b ≠ 0, и делитель не равен нулю, то есть a ≠ b.
  2. 1a − 1b = b − aab. Делим b − aab на такую же дробь, получаем 1.
  3. Проверка при a = 2, b = 3: (12 − 13) : 16 = 16 : 16 = 1.

Ответ: 1 при a ≠ 0, b ≠ 0, a ≠ b.

Задачи

Задача 1

с места, у доски · 3 мин · по мотивам № 150

Выполните действия:

(1x + 1y) : (1x − 1y)
Показать решениеСкрыть решение
  1. Допустимые значения: x ≠ 0, y ≠ 0, и делитель не равен нулю, то есть x ≠ y.
  2. Первая скобка: 1x + 1y = y + xxy. Вторая скобка: 1x − 1y = y − xxy.
  3. Деление заменяем умножением на обратную дробь: x + yxy · xyy − x = x + yy − x.
  4. Проверка при x = 2, y = 3: (12 + 13) : (12 − 13) = 56 : 16 = 5, а 2 + 33 − 2 = 5.

Ответ: x + yy − x при x ≠ 0, y ≠ 0, x ≠ y.

Задача 2

у доски и в тетради · 3 мин · по мотивам № 152

Упростите выражение:

(aa − 3 − aa + 3) · a² − 93a
Показать решениеСкрыть решение
  1. Допустимые значения: a ≠ 3, a ≠ −3, a ≠ 0.
  2. Скобка: aa − 3 − aa + 3 = a(a + 3) − a(a − 3)(a − 3)(a + 3) = 6aa² − 9.
  3. Умножаем: 6aa² − 9 · a² − 93a = 6a3a = 2.
  4. Проверка при a = 5: (52 − 58) · 1615 = 158 · 1615 = 2.

Ответ: 2 при a ≠ 0, a ≠ 3, a ≠ −3. Значение выражения не зависит от a.

Задача 3

самостоятельно, проверка у доски · 3 мин · по мотивам № 155

Представьте выражение в виде дроби:

2 − x² + 2xx² − 4
Показать решениеСкрыть решение
  1. Допустимые значения: x² − 4 ≠ 0, то есть x ≠ 2 и x ≠ −2.
  2. Сокращаем дробь: x² + 2xx² − 4 = x(x + 2)(x − 2)(x + 2) = xx − 2.
  3. Вычитаем из числа: 2 − xx − 2 = 2(x − 2) − xx − 2 = x − 4x − 2.
  4. Проверка при x = 3: 2 − 155 = −1, а 3 − 43 − 2 = −1. Проверка при x = 4: 2 − 2412 = 0, а 02 = 0.

Ответ: x − 4x − 2 при x ≠ 2, x ≠ −2.

Задача 4

самостоятельно · 3 мин · по мотивам примера 3 и № 157

Упростите «многоэтажную» дробь:

ab − ba1a + 1b
Показать решениеСкрыть решение
  1. Допустимые значения: a ≠ 0, b ≠ 0, и знаменатель большой дроби не равен нулю: 1a + 1b = a + bab, значит, a ≠ −b.
  2. Умножим числитель и знаменатель на ab. Числитель: (ab − ba) · ab = a² − b². Знаменатель: (1a + 1b) · ab = b + a.
  3. Получаем a² − b²a + b = (a − b)(a + b)a + b = a − b.
  4. Проверка при a = 3, b = 2: (32 − 23) : (13 + 12) = 56 : 56 = 1, а 3 − 2 = 1. Проверка при a = 5, b = 1: 245 : 65 = 4, а 5 − 1 = 4.

Ответ: a − b при a ≠ 0, b ≠ 0, a ≠ −b.

Дополнительная задача

если урок идёт быстро · 3 мин · по мотивам № 173 (пример 4 учебника)

Из пункта А в пункт В автобус ехал со скоростью 90 км/ч. На обратном пути из-за непогоды он снизил скорость до 60 км/ч. Какова средняя скорость автобуса на всём пути?

Показать решениеСкрыть решение
  1. Пусть расстояние от А до В равно s км. Время туда s90 ч, время обратно s60 ч. Весь путь 2s км.
  2. Средняя скорость: v = 2ss90 + s60. Сократим на s: v = 2190 + 160.
  3. 190 + 160 = 2 + 3180 = 136. Тогда v = 2 : 136 = 72.
  4. Замечание для класса: среднее арифметическое (90 + 60) : 2 = 75 даёт неверный ответ. Средняя скорость не равна среднему арифметическому скоростей.

Ответ: 72 км/ч.
